How YojanaMatch works

YojanaMatch is an independent website built by Nidhi Karuturi. It is not a Government of India website and it is not a state government website.

The database is a structured subset of schemes published on myScheme, the official scheme portal maintained for the Government of India. Each record keeps the official name, eligibility text, benefits text, documents, an apply link when myScheme lists one, the source URL, and the date the record was checked.

If the official page does not state a single benefit amount, that field is left blank. Amounts are not estimated.

The matcher uses myScheme’s own facet tags for state, gender, category, rural or urban residence, disability, occupation, employment, student-only schemes, and below-poverty-line schemes. Age coverage comes from the official age filter. An income ceiling is stored only when the eligibility text states one. A blank facet does not exclude anyone.

Where the official text says that a male applicant must be from the SC/ST category, that sentence is applied as written. It is stored next to the quote.

Eight questions cannot capture every condition, such as land in the applicant’s name. Read the eligibility on the scheme page and confirm it on the official portal before you apply. The catalogue is a verified subset, not every scheme in the country.
